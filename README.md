# Student Database Analysis

A MySQL-based project for managing and analyzing student data. This project demonstrates database creation, data insertion, filtering, sorting, aggregate functions, and SQL joins to generate meaningful academic reports.

## Technologies Used
- MySQL
- SQL
- MySQL Workbench

## Features
- Student and course management
- Data filtering and sorting
- Aggregate functions (COUNT, SUM, AVG, MAX, MIN)
- Performance analysis reports
- SQL JOIN operations
